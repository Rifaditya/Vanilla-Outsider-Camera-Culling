# 📷 Camera Culling 위키

**Camera Culling** 공식 문서 포털에 오신 것을 환영합니다. Camera Culling은 **Vanilla Outsider** 철학에 따라 개발된 Minecraft **26.1.2**, **26.2**, **26.3**용 고성능 클라이언트 사이드 렌더링 최적화 모드입니다.

> 📌 **저장소 소스 코드 면책 조항**: 본 위키의 문서는 CurseForge 및 Modrinth의 공개 릴리스 빌드보다 앞선 최신 미출시 커밋 또는 개발 중인 기능을 포함할 수 있는 **저장소의 현재 소스 코드 상태**를 반영합니다.

---

## 🧭 다중 버전 전환 포털

Camera Culling은 엄격한 **1 JAR 1 버전** 규칙에 따라 개발됩니다. 아래에서 사용 중인 Minecraft 버전을 선택하여 격리된 전용 문서 트리를 확인하십시오:

| 대상 Minecraft 버전 | 모드 릴리스 버전 | Java 런타임 | 빌드 툴체인 | 전용 위키 포털 |
| :--- | :--- | :--- | :--- | :--- |
| **Minecraft 26.1.2** | `1.10.2+26.1.2` | Java 25+ | Fabric Loom 1.15.5 | [[👉 MC 26.1.2 위키 들어가기|ko_kr-26.1.2-Home]] |
| **Minecraft 26.2** | `1.10.1+26.2` | Java 25+ | Fabric Loom 1.15.5 | [[👉 MC 26.2 위키 들어가기|ko_kr-26.2-Home]] |
| **Minecraft 26.3** | `1.10.1+26.3` | Java 25+ | Fabric Loom 1.15.5 | [[👉 MC 26.3 위키 들어가기|ko_kr-26.3-Home]] |

## ⚡ 핵심 최적화 매트릭스

| 최적화 시스템 | 주요 메커니즘 | 성능 향상 이점 |
| :--- | :--- | :--- |
| **제로 할당 레이캐스트 엔진** | 원시 좌표 기반 시선 검사 | 카메라 회전 시 JVM Young-Gen GC 일시 중단 스파이크 제거 |
| **안티플리커 시간적 히스테리시스** | 적응형 4/8/12프레임 거리 완충 버퍼 | 블록 모서리 스침 및 뷰 바빙으로 인한 깜빡임 제거 |
| **양면 표지판 텍스트 컬링** | 표면 법선 벡터 내적 ($\vec{N} \cdot \vec{V}$) | 표지판 텍스트 드로우 콜 50%–100% 감소 |
| **파티클 차폐 컬링** | 4m 근접 안전 버블 + 시각 클립 레이캐스트 | 지하 및 은폐된 파티클 쿼드의 렌더링 방지 |
| **애니메이션 컬링** | 텍스처 아틀라스 업로드 억제 | 3D 블록 애니메이션 및 오프스크린 텍스처 업로드 동결 |
| **몹 밀집 오버드로 방어** | 16m 빠른 실패 + 1.5m 클러스터 밀도 제한 | 밀집된 몹 농장 및 축사의 렉 스파이크 제거 |
| **거리 기반 텍스처 LOD** | 3단계 OpenGL 밉맵 바이어스 ($0.0 \to 1.0 \to 2.5$) | 원거리 몹 무리의 VRAM 필레이트 대폭 감소 |
| **보스 및 미니 보스 면제** | 동적 체력 임계값 및 이름 휴리스틱 | 게임플레이를 해치는 보스 컬링 방지 |
| **2단계 면제 블랙리스트** | 로컬 클라이언트 JSON + 서버 관리자 동기화 | 동반자 몹을 위한 사용자 정의 화이트리스트 |
| **블록 엔티티 차폐 컬링** | 6방향 완전 밀폐 감지 | 밀폐된 상자 및 블록의 렌더 상태 추출 생략 |
