## ⚡ コア最適化マトリクス

| 最適化システム | 主な仕組み | パフォーマンス上の利点 |
| :--- | :--- | :--- |
| **ゼロアロケーションレイキャストエンジン** | プリミティブ座標による視線判定 | カメラ回転時のJVM Young-Gen GC一時停止スパイクを排除 |
| **アンチフリッカー時間的ヒステリシス** | 距離に応じた適応型4/8/12フレーム猶予バッファ | ブロックの境界かすめや歩行時の揺れによるチラつきを防止 |
| **両面看板テキストカリング** | 面法線ベクトルの内積 ($\vec{N} \cdot \vec{V}$) | 看板テキストの描画コール（Draw Call）を50%〜100%削減 |
| **パーティクル遮蔽カリング** | 4mの近接安全バブル＋視覚クリップレイキャスト | 地下や遮蔽されたパーティクルクアッドのレンダリングをスキップ |
| **アニメーションカリング** | テクスチャアトラスのアップロード抑制 | 3Dブロックアニメーションおよび画面外テクスチャのアップロードを停止 |
| **モブ密集オーバードロー防御** | 16m高速早期判定＋1.5mクラスタ密度制限（8体） | 密集した家畜囲いやトラップタワーでのラグスパイクを解消 |
| **距離ベーステクスチャLOD** | 3段階のOpenGLミップマップバイアス ($0.0 \to 1.0 \to 2.5$) | 遠方のモブの群れによるGPU VRAM帯域幅とフィルレート消費を大幅に削減 |
| **ボス・ミニボス免疫** | 動的体力閾値および名前ヒューリスティクス | 戦闘において重要なボスの遮蔽カリングによる消失を防止 |
| **2段階免疫ブラックリスト** | ローカルクライアントJSON＋サーバー管理者同期 | ペットや相棒モブを保護するカスタムホワイトリスト |
| **ブロックエンティティ遮蔽カリング** | 6面固体閉塞判定 | 壁や床に埋め込まれたチェスト等のレンダリング抽出をスキップ |
